# Open-frame imaging kit

The `gla07512k-t2-itz1212ip-imaging-kit` product belongs to `systems` (整机系统). Both Chinese and English detail pages insert this experience immediately after `product-detail-top`. The existing PV400 experience and all other product sections are unchanged.

## Product scope

The supplied functional description identifies a lens, an SDI-output imaging core, a lens-to-core connector, a K10 SDI-to-Ethernet converter, and the K10 enclosure / heat-sink base. It is a customer-integrated component kit, not a handheld camera with a common enclosure. Airborne, vehicle and marine uses are integration scenarios, not certified capabilities. Resolution, focal length, frame rate, power, network protocol, encoding, latency and environmental ratings are deliberately unspecified. No price is invented.

`server/migrations/products/006_imaging_kit.sql` creates both localized records and, if missing, their categories. It is transactional and insert-only: repeated startup migrations do not overwrite management edits, republish drafts or duplicate products. No unrelated products are modified.

## CAD analysis

The supplied STEP file was generated by Siemens NX on September 21, 2024. It contains one flattened assembly with 69 unnamed solid bodies, not a named five-part assembly tree. The source SHA-256, tessellation settings and zero-based body assignments are recorded in `public/assets/models/imaging-kit/manifest.json`.

The viewer's five groups are a functional interpretation based on spatial relationships and the supplied component list:

| Group | CAD interpretation | Bodies |
| --- | --- | --- |
| Lens | Optical barrel, optical elements and associated fasteners | 14 |
| Core | Central imaging assembly, detector-region geometry and associated hardware | 11 |
| Adapter | Connecting flange between lens and core, with four fasteners | 5 |
| K10 | Rear converter boards, components and interfaces | 31 |
| Housing | Rear cover, heat-sink base and enclosure fasteners | 8 |

Every source body belongs to exactly one group. No replacement procedural geometry is used. The exported GLB uses meters and a rigid axis rotation; it preserves the assembled relationships. Display colors, highlighting, exploded distances and directions are explanatory, not manufacturer BOM information, material specifications or installation instructions. The poster is rendered from the same GLB, not generated from a product photograph or an AI image.

The customer-specified finish is matte black on every non-optical body and opaque, black mirror-like optics. Only lens bodies 44, 51 and 52 use the reflective material. Both GLB materials explicitly use `OPAQUE`; there is no transparent glass or transmission. Lighting and selection highlighting are neutral so they do not tint the black structures blue or green. The poster uses the same materials and lighting as the interactive viewer.

## Interaction and loading

- Lazy-imports the Three.js scene within 250 pixels of the viewport and loads the local GLB with an abortable request.
- Runs a repeating 26-second carousel: 2 seconds assembled, 2 seconds opening, five 4-second component presentations, then 2 seconds closing. The lens, core, adapter, K10 and housing highlights, descriptions and numbered controls advance together. Initial playback starts at the opening phase.
- Automatic carousel selection does not invoke the manual-selection pause handler. Pause, direct component selection, dragging and zooming stop the tour; Start carousel begins a fresh tour. Automatic description changes do not repeatedly announce through a screen-reader live region.
- The tour clock uses actual visible elapsed time rather than the capped physics step, so a lower frame rate does not stretch a 26-second cycle into minutes. Visibility changes reset frame timing to avoid skipping stages after returning to the page.
- Picking, numbered hotspots and five module buttons select functional descriptions. Selecting an internal module separates the kit to expose it.
- Supports pointer rotation, pinch/scroll zoom, arrow-key rotation, `+`/`-` zoom and `0` reset.
- Reduced motion disables autoplay and animated transitions. Offscreen and hidden-tab rendering pauses, and unchanged manual views do not redraw. Rendering is capped at 30 FPS and device pixel ratio at 1.6.
- WebGL or model-load failures retain the CAD poster, component descriptions, signal-chain explanation and retry control. Unmount aborts loading and disposes the scene, GPU resources, events and observers.

The UI shares scoped structural styles with PV400, with isolated five-module layout overrides. No PV400 behavior or global CSS is changed. The GLB and poster are committed assets; production has no CAD-conversion dependency.

## Regenerate assets

From the repository root, install offline-only tooling outside the repository:

```bash
npm install --prefix /tmp/cooyue-cad --registry=https://registry.npmjs.org --no-audit --no-fund occt-import-js@0.0.23 playwright@1.63.0
/tmp/cooyue-cad/node_modules/.bin/playwright install chromium
NODE_PATH=/tmp/cooyue-cad/node_modules node next/scripts/build-imaging-kit-model.cjs /path/to/source.stp
NODE_PATH=/tmp/cooyue-cad/node_modules node next/scripts/render-imaging-kit-poster.cjs
```

Obtain `source.stp` from `sourceUrl` in the manifest. The converter rejects a changed source checksum or an incomplete / duplicated body mapping. Review and update the mapping if the CAD is revised; do not silently reuse it. The poster renderer also requires the existing `next/node_modules/three` installation.

## Validation

Run `yarn tsc --noEmit` and `yarn build` in `next`. Validate the seed in PostgreSQL temporary tables before applying it. Verify both locale routes, the product's `systems` listing, the five descriptions and hotspots, autoplay / pause, pointer / keyboard controls, mobile overflow, reduced motion, failed-model retry and WebGL fallback. Check that PV400 still renders its own experience and unrelated products render neither one.

Run `npm run test:carousel` in `server` to verify ordering, transition bounds and repeated cycles. In a browser, keep the viewer visible for at least two complete tours and verify `01 → 02 → 03 → 04 → 05 → 01`, then test pause, manual selection, restart and reduced motion.
